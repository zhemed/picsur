# 自升级、灰度切换与 Node 退役

## Goal

把 Rust 服务安全地推到唯一入口，处理自升级子系统，最后退役 Node 与 Angular 构建链。

## Deliverables

- 灰度前门：Rust 监听 8080 做前门，按前缀与方法归属表转发到 127.0.0.1:8081 的 Node 实例，未命中回落 Node。
- 归属开关：`PICSUR_RUST_ROUTES` 一类环境变量，翻转即回滚；健康检查由 Rust 直接实现。
- 启动副作用单属主：图片清理、demo 清空、自升级自愈、种子、迁移执行同一时刻只允许一侧运行。
- 自升级处置：过渡期由 Node 侧车提供 `/api/system/update/*`，本阶段用 bollard 重写并接管，退役前必须有明确归属决策与接口归属文档。
- 镜像与发布：all-in-one 新镜像、`/data` 兼容、健康检查、回滚镜像留档、发布脚本更新。
- 退役：移除 Node 运行期与 Angular 构建链、清理过渡开关、更新 `docs/MAINTAINING.md` 与 `AGENTS.md`。

## Acceptance Criteria

- [ ] 单入口灰度下，未归属前缀的请求经 Rust 转发后与直连 Node 结果一致。
- [ ] 每个开关翻转后 1 分钟内可回滚，不需要回滚数据库。
- [ ] 同一分钟内的清理任务日志只出现一次，证明副作用单属主生效。
- [ ] 自升级三例通过且注明执行侧：正常升级、杀 helper 自愈、坏镜像回滚。
- [ ] 连续运行 7 天无回归，回滚演练 10 分钟内完成。
- [ ] 备份恢复演练通过，`/data` 备份可还原到旧镜像与新镜像。
- [ ] 文档中指向 Node 的部署与开发说明全部更新。

## Dependencies

依赖 03 至 08 全部完成；自升级默认在本阶段由 bollard 接管，仅当用户明确决定放弃该能力时登记例外，不得默认延后。
