# 执行计划：Picsur 全栈迁移到 Rust

本计划把迁移拆为 9 个子任务，按下表顺序推进。每个子任务都有独立验收门与回滚点，门未过不得进入下一阶段。

## 1. 前置条件

### 1.1 环境缺口

- 本机实测无 `rustc` 与 `cargo`（2026-10-31 `command -v` 无输出），子任务 02 的第一步是安装 Rust 工具链并写入 `rust-toolchain.toml`。
- 工具链版本必须一次钉死：trunk 0.22.1 要求 MSRV 1.96.1，sqlx 0.9 要求 1.94，取满足全部依赖的最高值并锁进 `rust-toolchain.toml` 与 CI。
- 过渡期旧实现仍需 Node 20 + pnpm 9.6.0；在子任务 09 完成前不要删除 Node 构建链。
- Docker 可用（29.7.2），all-in-one 与自升级演练需要它。

### 1.2 分支与协作

- 并行开发用 `git worktree add .worktrees/<stream> -b <branch>`，各线独立数据库 `picsur_<stream>`，Lead 统一集成。
- 每个提交必须带 `[task:<任务目录名>]` 锚点；任务目录必须有 `directive.md` 记录用户原话，否则提交闸门拒绝。子任务目录已预置 `directive.md`。

## 4. 提交与门禁节奏

1. 每个子任务结束时跑本阶段验收门，输出保存到任务目录 `research/` 或新 `evidence/` 目录。
2. 门全绿后提交，提交信息带 `[task:<任务目录名>]`。
3. 子任务归档后父任务更新进度；父任务在所有子任务完成后做集成审查与最终验收。
4. 任一阶段门红则停在该阶段修复，不允许带红进入下一阶段。

## 5. 回滚手册

| 场景 | 动作 |
|---|---|
| 某前缀功能异常 | 从 `PICSUR_RUST_ROUTES` 移除该前缀，重载配置，流量回 Node |
| 写路径异常 | 先停止新上传，排空在途请求，再移除写路径归属 |
| 前端页面异常 | `/v2` 下线或撤掉根路径 302，恢复 Angular 产物 |
| 启动副作用冲突 | 把 `PICSUR_JOB_OWNER` 统一指向一侧并重启另一侧 |
| 数据层异常 | 回滚镜像 tag，不执行任何 down migration；上线前必须 `pg_dump` |
| 自升级异常 | 移除 docker socket 挂载，按文档手动升级 |

注意：新版启动约 2 秒会清理同 lineage 的 `-prev-` 容器，回滚不能依赖它；必须在发布前记录旧镜像 tag 与数据库备份。
